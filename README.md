# MARS DRAGON RUN 🐉🚀

Google Chrome Dino o'yinidan ilhomlangan, **Three.js** yordamida yaratilgan 3D Endless Runner o'yini.

## Ishga tushirish (2 xil usul)

### 1-usul: VS Code Live Server orqali (hech narsa o'rnatmasdan)
1. `index.html` faylini VS Code'da oching.
2. O'ng tugmani bosib **Open with Live Server** ni bosing — o'yin darhol ishlaydi!

### 2-usul: Vite orqali (npm bilan)
1. Terminalni oching (`Ctrl + ~`).
2. `npm install` va keyin `npm run dev` buyrug'ini bering.
